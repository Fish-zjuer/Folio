# 个人待办的时间、重复与提醒

2026-10-14，按用户要求增加功能；目前为本地浏览器原型，不修改 Flutter 源码。

## 可创建、保存和再次编辑的字段

| 项目 | 行为 |
| --- | --- |
| 标题 | 简短名称，必填，最长 100 字 |
| 内容 | 独立多行正文，最多 5000 字；列表摘要两行，详情保留换行完整展示 |
| 类型 | 普通待办 / 自定义作业；作业可附课程备注 |
| 重要性与紧急性 | 两个独立标记，不把紧急误当成重要 |
| 不设时间 | 无 DDL、无固定时段；仍可手动指定挂载日 |
| 截止时间 | 截止日期，可附具体 HH:mm；未指定时刻时，提醒按当日 23:59 计算 |
| 指定时间段 | 开始日期与时刻、结束日期与时刻；支持跨日，结束必须晚于开始，不伪装为 DDL |
| 重复 | 不重复 / 每天 / 每周 / 每月；间隔 1–365；每周可选多个星期；结束日期可选 |
| 提前提醒 | 不提醒 / 到时 / 提前 10 分钟、30 分钟、1 小时、1 天 / 自定义分钟、小时或天 |
| 入队 | 默认关闭；普通事项也可主动加入统一队列，整组重复事项和单次挂载分别处理 |

输入时刻使用 24 小时 HH:mm，例如 09:00。设定开始时间或截止时间后，才有提前提醒的锚点。

## 重复与完成

- 每次安排有独立 ID、完成状态、挂载状态。完成本次后，列表显示下一个尚未完成的安排，不结束整组重复事项。
- 编辑重复事项时修改整组规则，表单时间表示首次安排；页面给出这条说明。
- 月末日期在较短月份取该月最后一天，例如每月 31 日在 2 月取 28/29 日。
- 首次日期很远时仍生成下一次安排，供列表查看；日历适配数据分别记录截止、时间段或全天重复日期。
- 浏览器原型预生成最近 7 天到未来 14 天的实例，并额外保留下一次；此前生成的未完成、已挂载和完成记录继续保留。真实应用的后台实例生成与长期历史处理后续接入。
- 改变重复规则时，没有挂载的未来实例可重新生成；已挂与已完成的历史实例保留。取消重复按表单日期保存为单次事项。

## 队列和热力图

- 自定义作业即使不入队仍出现在作业页；普通待办主动入队后也进入“自定义”行。
- 重复模板本身不计为一份作业；按各次实际安排计数。
- DDL 事项按截止日期分批，时间段事项按开始日期分批，全天重复事项按本次日期分批。日期没有改变类型，时间段仍保留真实起止时间。
- 热力图只显示剩余数量，不再提供全部 / 未完成 / 已完成筛选；这些筛选只属于列表，两种视图的选择互不干扰。

## App 内提醒的范围

提醒时间 = 开始时刻或截止时刻 − 提前量。提醒面板展示已到与尚未到的提醒，已完成实例不再提醒；按钮上的已到数量每分钟更新。使用当前示例日期与上海时区时钟计算。

这不是手机系统通知，也不会在浏览器关闭后唤醒应用；本轮不申请通知权限。后续迁入 Android 时再接手机通知和后台调度。

## 文件与验证

`todo-core.js` 管理验证、周期实例、完成与提醒时间；`todo-ui.js` 管理表单、详情和提醒面板。与 `homework-queue-core.js` 共用入队、挂载和日历数据适配。

测试命令：`node --test homework-queue.test.cjs todo-core.test.cjs`。目前 19 项通过，覆盖时段校验、跨日提醒、多个星期、月末、逐次完成和队列状态保持。
