# 日程模块：源码核对与新版衔接

已有可操作日程页初稿，菜单“日程”已开放；课程使用本地示例，作业与待办读取同一份本地状态。Flutter 源码不变。

## 原源码

| 来源 | 原有行为 |
| --- | --- |
| `../Celechron-main/lib/page/calendar/calendar_view.dart` | 月历/周历选择日期、返回今天、增加事项、下方当天安排，切换学期视图 |
| `../Celechron-main/lib/page/calendar/calendar_controller.dart` | 从教务 `periods` 取课程/考试等安排，合并 fixed/fixedlegacy 任务时段，按开始时间排序 |
| `../Celechron-main/lib/page/calendar/schedule_view.dart` | 学期课程表、学期信息等内容 |

原日历没有将新版作业挂载队列和作业截止日整合进去；不能直接按旧界面换皮处理。

## 已确定的数据规则

| 内容 | 日期或时间来源 | 状态与修改 |
| --- | --- | --- |
| 作业截止 | deadline，可选截止时刻 | 完成保留记录；改便签日期不改变截止 |
| 便签挂载 | mountDate | 手动改日后投影到新日期；完成后不再显示待挂事件 |
| 待办时段 | startAt–endAt | 保留真正开始/结束；跨日按每一天显示对应部分 |
| 重复待办 | 每次具体实例的日期和时间 | 不显示重复模板，每一次分别完成 |
| 不设时间的普通待办 | 无 | 不凭空放进某一天；明确指定挂载日则产生挂载事件 |

`homework-queue-core.js` 的 `calendarEntries()` 提供独立事件。
新增 `calendar-core.js` 的 `dayEntries(entries, date)` 按日投影，不缓存副本、不修改源数据，完成和改日后重新读取即可刷新。

- 午夜 00:00 结束不额外占次日。
- 跨日事件保留原始开始/结束，提供当天分钟范围及前后延续标记。
- 只设日期、没有具体时刻的事项保留 `allDay` 数据标记，但显示在“当天要做”的独立卡片区，不接时间线，不伪造开始时刻。设了具体时刻的作业/待办与课程统一按时间排序、连线和定位。
- 数据层不决定月历色块、事件图标、时间轴样式或页面结构。

## 已按用户指定的布局制作

- 日历收放：在日历上向上滑动，保留当前选中日期所在周，其余周折叠；向下滑动恢复整月。行高与日历平移跟随手指，松手后 320ms 缓动；位移不足 36px 或取消手势时回弹。日期选中不变，下方日程独立滚动且获得释放的高度。原有左右滑课表继续可用。
- 点击月份标题也可收放，标题含小箭头及 aria-expanded；键盘可激活，桌面滚轮可收放。收起时导航箭头为上一周/下一周，展开后为上个月/下个月；返回今天、跨月和页面往返保持本轮收放状态，刷新默认展开。隐藏周设置 inert 和 aria-hidden，避免键盘进入看不见的日期；减少动态效果时无过渡。
- 不新增页面、滚动条或底部遮挡层。五行月历从 250px 收为 50px，下方增加约 200px；六行月份和短屏按实际行高测量，窗口变化后重新同步。
- 上方月历：当前周为浅暖灰整行底色，今天为灰色圆角方底；选择其他日期保留今天标记，以细边框表示选择。
- 日期下方一门课程一个圆角小方块，最多四个；更多课程用“＋”表示。按钮的无障碍名称保留完整课程数量，点击日期后下方显示所有课程。这里只统计课程，不把作业或待办冒充课程数量；日期旁的课程数胶囊已移除。
- 下方当天安排：左侧衬线加粗时间，中间为课程颜色圆点与连接线，右侧白色卡片内显示课名和地点图标。圆点与时间数字居中对齐。当前事件用空心圆点、对应色时间及细边框突出，不显示“正在上课”标签。独立滚动，无滚动条，前后隐藏内容有数量提示。
- 卡片最右侧 60px 为像素形象折返路线：下、左、上、左、下至左下终点。8×8px 方块连续相接形成实线，比上一版粗两倍；吃过的部分回到卡片底色，剩余部分保留实课程色。横向两次折返等距，两侧边距相等；纵向跨度留出形象安全边距，取整到像素网格。
- 路线与小图标只出现在今天当前进行的那一项，最多一处；未来课程没有路线、图标或右侧占位，已结束课程仅保留灰色卡片。没有当前事项时整页没有路线。指定时段的个人待办也适用，跨日时按原始完整时段计算进度。
- 默认形象改为抽象小书本。`pixel-avatar-core.js` 管理统一 16×16 图案和预设；编辑页可自行绘制，所有图案映射为 24×24。入口为设置的“进度形象”和课程详情的“自定义进度形象”。卡片增高时重绘路线，形象不侵入文字。
- 两节课标一次课间，三节课标两次课间；绿色转角表示进入课间，蓝色表示结束课间，棕色终点表示课程结束。三节课的两个横向折返正好对应两次课间；两节课第一个折返对应课间，第二节走完其余路线。宠物按分段时间映射到路线，不按几何长度直接等分。当前示例为每节 45 分钟、课间 5 分钟，课程详情展示节次和课间时刻；尚未接入真实节次数据。
- 时间轴经历的连接段为实线，当前事件下方及未来连接段为虚线。唯一倒计时居中放在左侧虚线上，无背景；进行中为 12px，事件结束后等待下一项时为 20px，并通过 520ms 气泡式缩放过渡。11:00 显示 7h50m，12:30 显示较大的 6h20m。已完成事项不作为当前事件；个人时段待办也可作为当前事件。第一项之前、最后一项之后和非今天不显示倒计时，减少动态效果设置下关闭动画。
- 今天定位当前事项；等待下一项时定位刚结束的事项以保留倒计时上下文；第一项之前定位接下来的有时刻事项，全部结束后定位最后一项。课程、作业时刻和待办同等参与；只有日期的事项不参与时间位置竞争。手动滚动和每分钟刷新保留当前位置，点击“定位现在”可重新定位。
- 切月、返回今天、选择日期、课程时间地点详情可操作；加号复用待办编辑表单，预填选中日期和指定时间段。
- 作业截止、便签挂载日、个人待办/重复实例和跨日片段都在当天安排中显示，点击进入既有详情，完成与改日使用原记录。
- 六行月份压缩日期行高度，避免进一步挤占当天安排区域。
- 独立事项显示具体信息，例如“微积分 · 10 月 15 日截止”；有时刻时显示“09:45 截止”；便签日显示“推荐这天做”。不再使用“截止安排”“便签挂载日”“跨日安排”作为卡片说明，跨天事项直接展示完整起止日期和时刻。

为显示进度造型与单处时间差，预览支持 `?previewTime=11:00`，定位按钮会明确显示演示时刻。无此参数则按上海时区的实际时刻。该参数不改变设备时间或保存的事项。

`course-data.js` 集中管理课程示例，`calendar-ui.js` 引用同一份数据；示例日期仍由作业页的日期控制。考试已接入本地教务示例和自定义考试仓库：考试日期数字右上角为 4px 灰赤红点，按最新反馈取消考试日期底色，让今天灰底保持主要视觉引导；当天时间轴中的时间/教室/座号、详情和编辑即时联动。课程方块仍最多四个加溢出加号。没有真实教务或模型接入，详见 `EXAM-FEATURES.md`。学期视图是否保留仍待后续确认。

周课表已作为日程内部视图放在月历右侧：向左滑进入，向右滑返回，顶部按钮也可切换。课表与月历通过同一日期投影读取实际课程，按教学周的单双周、短学期、起止和指定周次筛选；小方块数量与当天安排同步。点击列头日期回到对应当天安排。学期选择器和隐藏课名开关仍待筛选，真实教务校历未接入，详见 `TIMETABLE-FEATURES.md`、`TEACHING-WEEKS.md`。
