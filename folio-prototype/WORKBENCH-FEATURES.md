# 自定义工作台

## 已确定

- 用户指定：左上、右上、左下、右下默认四个灰色虚线框，可以自由添加组件或留空；组件逐个设计，不预填课程、成绩等内容。
- 最新布局：左上时间、右上天气，中间四宫格，下方便签。替代原先撑满屏幕的细长四格和右侧便签布局。
- 时间使用设备时钟，按 Asia/Shanghai 显示时分与日期；进入工作台和恢复前台时更新，显示期间每 10 秒更新一次。
- 天气暂为固定的“多云 · 22°”视觉示例，明确标为示例，无定位权限、天气请求或实际天气结论。
- 中间两列两行等分，3px 粗灰虚线；短屏适度收缩四格高度，优先保留下方便签。暖白画布、中央加号保留。
- 顶部至少留出 56px，有系统安全区时取安全区加 12px；短屏不取消此留白。便签板最低 200px，短屏 180px，为顶部摄像头区域让出空间。
- 下方最新采用用户 `sticky-desk.html` 的浅色插画书桌风格：折角纸、胶带、平移硬阴影，咖啡／铅笔／盆栽／收纳盒。替代木纹板、黑板及织物方案。原样式文件保存在 `assets/sticky-desk-reference.html`，详细约定见 `STICKY-DESK-ADAPTATION.md`。
- 便签为小尺寸无字折角纸；三种折角大小、随机轻微倾斜与尺寸变化，取消大卡片和区块标题／数量。不再沿屏幕右侧画绳索。
- 首页向左划进入；工作台向右划回到原对话。侧栏也可进入，顶部可回首页或菜单，Esc 回首页。
- 切换为平滑横向滑动，系统减少动态效果时直接切换；纵向操作与输入控件不参与横滑。
- 点击空格打开组件选择；当前组件库为空，可保持空白，关闭或 Esc 返回对应插槽。弹层限制焦点在弹层内。
- 不改动原对话、附件与待确认草稿。

## 下方便签

- 使用 `FolioQueue.rail(homeworkState.items)`，只展示已挂上、未完成的队列事项；明确入队的个人待办也会出现，不凭空添加示例便签。
- 点击便签打开独立阅读窗，只显示科目、标题、来源链接；有真实描述和附件字段时显示，不再带出原管理表单或截止日期。改期和完成仍在完整作业／待办页进行。
- 便签表面不显示标题、科目、日期、倒计时或临期文字；也不放 title 悬停提示，ARIA 仅为“打开便签 N”。
- 使用参考文件的五组粉彩配色，不根据截止日期或重要性染色。颜色和纸张形态按事项 ID 本地保存，旧颜色映射到同类新色；新增便签随机配色时避免与前一张相同，相邻折角大小不同。
- 位置通过随机候选中择取与已有位置最分散者生成，少量时散放，积累后自然叠压。位置使用归一化坐标，随容器尺寸适配。数量很大时扩展内部区域并可独立滚动，不缩纸、不显示滚动条；下方有内容用小箭头提示。键盘聚焦／悬停将该纸张提升到最上层，便于访问叠压事项。
- 临期按完整可用日分阶段：2～3 天冒烟，≤1 天半透明火焰覆盖纸面。暂用早 8 点为凌晨分界，凌晨截止归前一晚；不将只有日期的 DDL 补成零点。以日历可用日而非剩余24小时计算。
- 着火样式采用用户 `fire-notes.html` 的四层火舌、上飘火星与纸张顶部的双层焦边，按中等燃烧示例缩放到原小便签；冒烟仍为轻烟团。系统减少动态效果时静止。
- 没有便签时挂板留空，不填假任务。原有队列、临期计算及其他页面不受影响。
- 当前天气、便签造型和四格组件都属于本地视觉原型；不接入真实天气、教务或系统通知。

## 组件接口

`workbench-ui.js` 提供 `FolioWorkbench.register({ id, label, mount(container) })`，供后续逐个确认的组件接入。注册组件后会出现在选择器，各格独立选择，可以重复选择；有内容时可更换或清空。

`folio-workbench-v1` 保存四格组件 ID、`noteColors` 事项配色及 `noteShapes`（位置、旋转、缩放、卷角变体）；默认四格均为 null，未识别组件 ID 以空格显示，不自动替换。组件自身数据和行为后续确定。当前不提供未经确认的测试组件。
