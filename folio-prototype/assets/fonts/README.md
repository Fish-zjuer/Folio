# 字体资源

`JetBrainsMono-Regular.woff2` 来自 JetBrains 官方仓库，用于学分徽章的等宽数字和 CR 单位。

- 来源：https://github.com/JetBrains/JetBrainsMono/blob/master/fonts/webfonts/JetBrainsMono-Regular.woff2
- 许可：SIL Open Font License 1.1，完整原文见同目录 `JetBrainsMono-OFL.txt`。
- 本地加载，无第三方字体请求。中文学期标题使用系统已有的 Noto Serif SC / Songti SC。
