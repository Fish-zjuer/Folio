# Folio 隐私说明

**版本：v1.0**  
**生效日期：2026-10-21**

Folio 是一个本地优先的校园信息整理工具。默认情况下，Folio 没有自建账号系统，也没有把个人记录上传到 Folio 服务器的功能。

## 1. 本机保存的数据

- 你创建或导入的待办、作业、日程、课程目标、专注记录、学习记录、天气/资讯缓存与设置；
- 学校教务返回的课表、成绩、考试、作业与实践缓存；
- 学校登录会话与加密保存的账号信息；
- 你配置的 AI 服务 Base URL、模型名称与 API Key（API Key 由 Android 原生层加密保存，不写入网页可读存储）。

这些数据通常保存在应用私有目录与 WebView 本地存储中。卸载应用或清除应用数据会删除它们；已导出的文件由你自行保管。

## 2. 会联网的功能

- **学校教务**：登录与数据请求直接发往学校系统；会话 Cookie 保存在本机。Folio 不把学校密码或 Cookie 上传到自有服务器。
- **AI 对话**：只有在你配置模型并主动发送时，相关文本、图片或上下文才会发送给你选择的 AI 服务商；适用其隐私政策与计费规则。
- **天气/资讯**：请求发往 Open-Meteo、Hacker News 等公开服务；不会携带你的学校账号。
- **公开数据**：不包含你的个人记录。

除上述请求外，Folio 不包含自建统计、广告 SDK 或用户画像服务。

## 3. 权限

Folio 可能请求以下可选权限：

- **通知**：发送本地成绩/提醒通知；
- **使用情况访问**：统计本机应用使用时长，用于工作台卡片；
- **相机/相册**：添加图片或拍摄附件；
- **精确闹钟/开机广播**：恢复本地提醒。

拒绝权限不会影响不使用对应功能的部分。你可以在系统设置中随时撤回权限。

## 4. 第三方

学校系统、AI 服务商、天气/资讯服务与 GitHub 各有自己的隐私政策。Folio 无法控制第三方的数据保留、跨境传输或二次使用；使用前请自行确认。

## 5. 数据删除与备份

- 删除单条记录：在 Folio 内删除；
- 清空本机数据：系统设置 → 应用 → Folio → 存储 → 清除数据；
- 卸载应用：删除应用私有数据（已导出文件除外）；
- 备份：使用 Folio 的导出功能，或自行保留重要记录。

## 6. 安全边界

Folio 会使用 Android 应用沙箱、HTTPS、CSP 与本地加密保存敏感配置，但任何软件都不能保证绝对安全。请勿在公开 Issue、截图或论坛中暴露学号、密码、Cookie、API Key 或他人个人信息。

## 7. 联系方式

隐私问题请通过 [GitHub Issues](https://github.com/Fish-zjuer/Folio/issues) 联系；涉及敏感信息时请先脱敏，或只说明问题类型，不要附上原始凭据。
