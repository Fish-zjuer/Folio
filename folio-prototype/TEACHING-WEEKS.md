# 单双周、短学期与指定周次

已按用户要求核对原版 `lib/model/session.dart`、`semester.dart` 及课程/课表界面。单双周属于每条上课安排，不能只写在课程标题上，也不能用自然周或 ISO 周号代替教学周。

## 共用数据规则

`course-data.js` 的每个示例学期可提供 `calendar.periods`：短学期名称、起止日期、上/下半学期标记及 `weekOffset`。短学期第一周可以从周中开始，星期一换周；进入下一个短学期时单双周重新从第 1 周起算。`semesterWeek` 通过 offset 保留整个长学期的周次，供指定周次、起止周判断。

每条 session 保留：

| 字段 | 含义 |
| --- | --- |
| day / start / end / room | 独立的星期、时段和教室 |
| firstHalf / secondHalf | 秋/春与冬/夏是否上课 |
| oddWeek / evenWeek | 两者均真为每周，仅一个真为单/双周，均假则不上课 |
| startWeek / endWeek | 整个长学期的起止教学周，含边界 |
| customRepeat / customRepeatWeeks | 指定长学期周次；与原版一致，指定周次优先于常规单双周及半学期标记 |

`weekInfo()` 计算教学周；`sessionOccurs()` 判断某条安排在某日是否发生；`onDate()` 生成实际课程实例。月历数量、当天安排和周课表统一调用这个入口。不同规则的记录不会被误合并成每周课程；单/双周互补的两门课不会产生伪冲突。时刻、地点读取具体 session，不从课程第一条安排猜测。

## 视觉适配

- 周课表标题下显示“秋 · 第 2 周（双周）”等说明；单/双周课程块带简短标记，仍只出现本周实际上课的安排。
- 课程单列/双列摘要按“教室 + 周次规则”合并相同规则的星期；不同规则分别显示，例如“周四 · 双周”和“周六 · 单周”。列表仍不显示具体时间。
- 课程详情按每条安排分别显示星期、时间、单双周或指定周次、短学期和起止教学周、教室。日历/课表点开的具体课程弹层还显示该日期处于哪个教学周。
- 原有月历折叠、考试标记、学分小数和布局切换继续保留。

## 当前示例与接入边界

仍是本地原型，不是实际教务课表。实验课示例设置为周四双周、周六单周，均为第 1–16 教学周；其余示例课每周。首段仍从 2026-10-08 开始，补充示例秋/冬分段：秋至 11-29，冬从 11-30 至 2027-01-24，冬的全学期周次 offset 为 8。原先“固定每周模板到 11-30 截止”的临时限制已移除，可浏览示例冬学期。

真实学期起算、节假日停课、调休与补课日期尚未接入；后续须从教务校历/已生成的实际课程日期读取，不能把上述示例日期当成学校真实安排。源 Flutter 未修改。

## 验证

课程数据 7 项测试通过，覆盖：非自然周起算、首周边界、冬学期重启（含前半段奇数周长度）、同课单双周不同安排和地点时刻、起止周、指定第 2/10/17 周、互补课程不误报重叠、学分小数和原始数据不变。与日程/课表/考试合测 25 项通过。
