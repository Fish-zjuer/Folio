# 成绩换算规则

依据：用户于 2026-10-15 提供的成绩换算表图片。原始成绩文本、计分制式、教务原始 `jd` 和本地派生值应分别保留。下面是本地换算函数的规则，不把未知值当零。

## 百分制 → 五分制绩点

| 百分制 | 绩点 | 百分制 | 绩点 |
| --- | ---: | --- | ---: |
| 95–100 | 5 | 74–76 | 3 |
| 92–94 | 4.8 | 71–73 | 2.7 |
| 89–91 | 4.5 | 68–70 | 2.4 |
| 86–88 | 4.2 | 65–67 | 2.1 |
| 83–85 | 3.9 | 62–64 | 1.8 |
| 80–82 | 3.6 | 60–61 | 1.5 |
| 77–79 | 3.3 | 0–59 | 0 |

表中分档是整数。94.5 等小数成绩的取整/分档口径尚未明确；原始小数保留，当前不擅自四舍五入或截断、不将未知换算当作 0。真实接入可读取对应教务 `jd` 并核对该情况。

## 五级制 → 五分制绩点

| 原始等级 | 字母 | 绩点 |
| --- | --- | ---: |
| 优秀 | A | 4.5 |
| 良好 | B | 3.5 |
| 中等 | C | 2.5 |
| 及格 | D | 1.5 |
| 不及格 | F | 0 |

直接查此表；**不经过百分制中转**。例如良好为 3.5，而百分制 80 分是 3.6；中等为 2.5，而百分制 70 分是 2.4。支持汉字、字母和“优秀（A）”等组合，但矛盾组合或未给定等级不猜测。

## 二级制

合格（P）、不合格（F）均不计 GPA：分子、分母都排除。不能将二级制 F 与五级制 F 混淆，后者是计入 GPA 的不及格 0。是否获得学分由独立字段决定。

## 与原版、其它数值的关系

- 原版 `Grade` 直接从接口 `jd` 读五分制绩点；本轮为离线原型新增上述明确换算函数。真实接口接入后保留教务原始 `jd` 并与表核对，冲突不能静默改写教务原值。
- 原版等级→百分制均分的换算（优秀90、良好80、中等70、及格60、不及格0）仍独立保留，用户这张表没有规定反向百分值。本表只确定绩点映射；该百分值不能拿来再算五级制绩点。
- 4.3 制与传统 4.0 制转换暂沿用原版已有函数规则。本地核心课 ×1.2 在各制式的基础绩点确定后施加，原始分数/学分不变。
- `academic-core.js` 的 `fivePointScore` / `gradePoints` 集中实现；`academic-data.js` 的样例调用同一函数，避免测试与界面各用一套公式。
