# 2×2 卡片的二级菜单（2026-10-20，未打包源码）

本轮针对“不同点击都打开全部记录、从顶部平铺文字、缺少视觉引导”的反馈。
18 枚独立学习卡与 8 枚便当接入上下文菜单；每日压力、专注账本、任务账本、课程统计的旧详情也改为相同层次。其他旧组件已有按日期/事项定位的入口，未在本轮改画。

## 行为

卡片绘图、参考模板、分区比例、原内距、SVG 边缘均保持。`library.js` 传递 motif（实际点击的图形语义），`study-menu-hit.js` 只添加记录/日期元数据，通过点击坐标命中 inert 模板内部；不在绘图中插入标题或接管触摸拖拽。

| 入口 | 菜单首要内容 | 继续操作 |
| --- | --- | --- |
| 今日时间蛇／便当竖轴 | 点中的课程或个人时段；空白处是当天概览 | 时间地点、个人安排编辑、完整日程 |
| 下一课环 | 最近下一课 | 开始时间、地点、距离开始 |
| 周积木 | 点中那一列的日期 | 当日排课、切其他日期 |
| 三件事／DDL／象限 | 对应任务；象限空白处按象限筛选 | 原任务详情、作业拆解 |
| 已交纸张 | 学校明确已交记录 | 不混入仅本地完成的作业 |
| 作业拼图 | 当前确认计划对应的作业 | 步骤计划、AI草稿；下一步突出，完成步骤折叠 |
| 书脊／课程色块 | 对应课程 | 剩余排课、该课程复习卡 |
| 马赛克／待复习格／曲线 | 对应知识点，或该图形的复习队列 | 问题、复习轨迹、明确自评；AI作答评估折叠 |
| 闪卡扇 | 单击换卡、双击列表、上滑当前卡 | 打开实际处于前面的卡，不固定第一条记录 |
| 沙漏／登山 | 最近一场未结束考试 | 日期、考场、待考/已结束筛选 |
| 多米诺 | 点中那场考试 | 只读考试详情，不用点击伪造考完状态 |
| 专注蛇／番茄／时段带 | 今日实际专注与会话 | 开始/继续计时、已保存时段 |
| 连胜／专注柱 | 连续天数或点中日期的账本 | 七日柱、当天会话、完整账本 |
| 月相 | 对应那一夜 | 手动记录/修改那一夜，保留日期 |
| 咖啡／作息弧 | 今日杯数或当前作息 | 睡眠、咖啡、当天安排入口 |
| 三环 | 专注/任务/复习三个方向 | 点环突出对应行，进入该类记录；设置不是默认入口 |
| 绩点台阶／课程环／走势 | 本学期汇总／点中课程／点中学期 | 沿用成绩隐私设置，隐藏时不产生数值与记录列表 |

## 视觉层次

面板沿用现有弹层及系统返回逻辑。顶部是语境与日期，其下是淡底重点区、较大的数值、一个主要操作，再显示相关分组。课程色标、考试状态、复习到期状态用于辨别记录。

超过六条的同组记录默认折叠余项，可搜索当前组；说明与计算依据在底部折叠。选中记录有返回概览入口。复习从题目开始，AI评估在折叠区中；作业计划突出尚未完成的第一步。

## 文件与扩展边界

- `study-menu-core.js`：纯选择与筛选规则。
- `study-menu-hit.js`：图形命中元数据，不改变原图。
- `study-menu-ui.js`：上下文菜单与旧数字卡可复用的 `records` 展示器。
- `study-ui.js`、`study-tools-ui.js`：原确认/录入流程继续承接操作。
- Widget API v1 保持兼容；tasks 快照补可选 `source`，避免丢失学校已交来源；coursesOn 补可选 `personal/itemId`，支持个人课程安排编辑。
- SDK 并非远程代码沙箱，本轮没有引入远程插件或放宽权限。
