# 卡片包（2026-10-20，未打包源码）

在四格的“添加组件”中选择“卡片包”，占用一个格子。空包点击加号放入现有卡片，之后横滑切换。按用户最新要求，不显示底部序号或圆点；卡片与托盘的几何中心重合，向外扩展4px的灰色托盘（浅色#969D94，深色#505B52），没有底部额外留位。

长按外层托盘进入整个包的编辑：管理包、更换、整包移除、完成。管理面板可以继续放入卡片、调整顺序、移除其中一张。工作台拖动和移除处理整个包，撤销恢复包内顺序及选中页；移除不会删除卡片对应的课程、待办或学习记录。

## 存储与生命周期

- 保留`folio-workbench-v1`的四个字符串槽位；包使用独立`pack:UUID`实例ID，内部配置在`folio-card-packs-v1`。不迁移或清空现有四格。
- 每个包独立保存卡片实例key、组件ID、顺序和当前页。同种卡片可重复添加。失去注册的开发者组件保留ID并显示占位，不擅自删配置。
- 只挂载当前与左右相邻页，其余页不运行组件。失去邻接或整包移除时执行真实组件的清理。非当前页inert，SDK不会向其推送数据或从其跳转。
- 复用现有注册表与真实mount/preview，外部Widget API v1组件同样能放入包，无需改写。禁止嵌套包，防止递归挂载；单包最多64张。
- 包移除后配置保留以支持原有撤销，布局中不再显示。保存失败会提示，不推进内存配置。
- 手势表面使用`data-gesture-lock`，横滑不触发首页/横向浏览翻页；纵向交回滚动。长按继续交给整个工作台包的拖动。鼠标、触屏及仅聚焦托盘时的左右方向键均支持切换。
- 通用FolioGesture增加可选destroy，清理包销毁后遗留的窗口监听；既有调用继续兼容。

文件：card-pack-core.js（纯配置/选择）、card-pack-ui.js（宿主组合）、card-pack.css，配合workbench-ui.js、widget-sdk.js、gesture-core.js和study/library.js。
