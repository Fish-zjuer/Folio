# 日程内的周课表

状态：已制作本地示例初稿。课表合并到日程，不增加独立页面或菜单入口。

## 原版有什么

| 功能 | 源码依据 | 用途 |
| --- | --- | --- |
| 选择学期 | course_schedule_view.dart 的 _semesterPicker | 查看不同学期课表 |
| 上下半学期选择 | course_schedule_controller.dart 的 firstOrSecondSemester | 切换秋/冬或春/夏对应课程 |
| 一周课表 | course_schedule_view.dart 的 _courseSchedule | 星期一到星期日，左侧十三节课及开始时刻 |
| 按节次占据高度 | _buildCourseScheduleByDayOfWeek | 两节/三节课程覆盖不同数量的格子 |
| 课程冲突 | 同上与 course_card.dart | 重叠课程汇入同一块，点击后选择查看哪一门 |
| 课程详情 | course_card.dart 的 onTap | 查看课程完整信息 |
| 隐藏课程信息 | course_schedule_view.dart 页尾开关 | 隐藏课名和地点，只看色块，仍可点开 |
| 单双周数据 | model/session.dart 与 model/semester.dart | 根据课程的单周/双周条件生成学期安排 |

以上路径相对 `../Celechron-main/lib/`；原版没有自动等价于本原型的逐周切换，不能把学期总课表直接当成某个具体星期。

## 当前实现

- 日程在左、周课表在右：向左滑进入课表，向右滑返回月历；顶部“日程 / 课表”也可切换。
- 星期一至星期日共七列，左侧显示十三节课和开始时间。课间与午间空白压缩，课程块根据真实起止时刻映射高度。
- 与月历共用同一份课程示例和配色，今天列浅灰；上一周、下一周、本周可以切换。点击列头日期返回对应日期的日程。
- 课程按示例教学周校历和每条安排的单双周、短学期、起止/指定周次过滤；本周不上的课不显示，月历方块及当天安排同步。标题下显示教学周与单双周，课程块保留简短规则标记。详情显示完整周次规则。
- 点击课程查看完整标题、时间、地点；长标题在色块内换行并截断，不越过列宽。重叠课程归并，点击后选择要查看的一门。
- 课表内部可以上下滚动，隐藏滚动条；下方有未显示课程时提示“下方还有课程 ↓”，到底消失。

单双周、上下半学期及指定周次规则已接入本地课程模型，详见 `TEACHING-WEEKS.md`。独立学期/上下半学期选择器和隐藏课名开关仍待逐项决定；真实教务校历、放假调休未接入，源 Flutter 不变。时间映射和重叠分组由 `timetable-core.js` 管理，日期规则由 `course-data.js` 管理，视图与手势由 `timetable-ui.js` 管理。
