# 像素形象规范与编辑

- 绘制统一采用 **16×16** 格，每格为六位 Hex 颜色或透明。预设和自绘使用同一数据格式。
- 课程卡片和实尺寸预览统一映射为 **24×24 CSS px**，透明格保留卡片底色。图案位置仍由课程进度决定。
- 进度路线为 **8×8px** 连续实色方块，上一版为 4×4px；两节/三节课的课间映射不变。
- 路线和形象只在当前进行的事项中出现；未来事项和已结束课程不保留图标。已结束课程显示灰色卡片。
- 预设为小书本、小猫、小兔、小熊、小足球，以及空白/已保存的自定义形象。默认小书本。
- 小书本只参考用户提供的书本图案，转换成标准 16×16 整格：阶梯封皮、暖色展开双页、细书脊、左页三条文字线、右下垂出的红色燕尾书签。编辑页布局不随参考图改变。
- 点击或拖动绘制；触摸只在画布内绘制，画布外保留页面滚动。方向键选择格子，空格或 Enter 绘制。
- 提供画笔、橡皮、十二色色板、自选颜色与 Hex 字段。清空和选择预设也能撤销；最多保留五十次编辑历史。拖画一笔只占一次历史。
- 点“应用”才替换所有课程卡片中的形象，保存到本浏览器 localStorage。空白图案不能应用；返回或 Esc 丢弃本次草稿，不改已应用图案。
- 保存自定义后切换并应用预设，仍保留此前自定义图案；重新点“自定义”可继续画。
- 入口为设置 → 进度形象，或任一课程详情 → 自定义进度形象。应用或返回时回到来源页。
- 不上传数据、不创建账号、不接入 Flutter；预设和画布尚为可调整的视觉原型。

`pixel-avatar-core.js` 管理规格、图案、校验和 SVG；`pixel-editor.js` 管理绘制、草稿、撤销/重做和保存；`snake-progress.js` 管理课程时间与路线。
