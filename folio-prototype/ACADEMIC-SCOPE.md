## 用户截图明确要求的基础能力

| 分组 | 必须覆盖的内容 | 范围与口径 |
| --- | --- | --- |
| 查找与学期 | 搜索课程/事项、学期切换 | 搜索结果跳转对应现有功能；学期切换影响的模块需明确 |
| 成绩 | 五分制、获得学分、四分制两种口径、主修均绩、主修学分、百分制 | 原版顶部为累计成绩，不能把累计结果误标为当前学期统计；支持明确切换累计/学年/学期 |
| 课程 | 课程数、所选课程学分、考试数 | 与已做课程/考试数据一致；所选课程学分和已经获得学分为不同字段 |
| 课时 | 秋/冬（或春/夏）两段课时与“两周”单位 | 考虑单双周、指定周次、起止周和短学期，标明统计区间，不能只把每周模板乘二 |
| 状态 | 每模块更新时间、刷新与失败/旧数据状态 | 真实接入前标为本地示例；无数据不显示虚假“0 分钟前已更新” |
| 跳转 | 成绩明细、课程、考试、日程内课表 | 总览呈现浓缩信息，具体编辑与完整列表沿用已有页面 |

截图中的具体数值仅作视觉参考，不复制为用户真实成绩或新原型的教务数据。

## 原版代码已有、需要在新版中安排的能力

- 成绩明细、学期/学年统计及主修统计。
- 选择部分课程计算绩点、学期批量选择和保存选择。
- 自定义倍率计算：原版对每门课的绩点乘倍率，再按原学分加权，**并非**单纯更改学分权重。若保留，应给出名称/公式说明，与普通学分加权均绩区分；新规则由用户确认。
- 重修首次/最高策略、课程代码映射、隐藏绩点设置。
- 作业汇总及第二/三/四课堂记点、美育/劳育通过状态。作业已有独立页与队列；总览可放摘要和入口，具体摘要形式待确定。
- 不计入 GPA 与不计入已获学分为不同状态；及格/不及格二级制、待录、缓考、弃修等应保留真实原始状态。

已核对来源：`../Celechron-main/lib/page/scholar/scholar_view.dart`、`scholar_controller.dart`、`grade_detail/`，以及 `lib/model/grade.dart`、`semester.dart`、`lib/utils/gpa_helper.dart`。只读核对，没有修改 Flutter。

## 增强项范围

2026-10-17：用户已明确新增目标均绩页，自动分配本学期课程目标、提供可替换组合，并在选定后联动课程提醒。该项已从候选转为待设计需求，详细约定与尚待确认的口径见 `GOAL-FEATURES.md`。下表其他方向仍为候选，不视作已承诺实现。

| 方向 | 可解决的实际问题 | 需要的数据 |
| --- | --- | --- |
| 学分/毕业进度 | 已修、在修、待修；按必修/选修/通识等类别查看差额；主修和培养要求的进度 | 可靠培养方案、要求分类、课程归属、认定/免修/重修等规则；缺失时显示未知，不推断“毕业已达标” |
| 成绩分析 | 历学期变化、学分和均绩变化、成绩分布、挂科/待录/重修筛选、搜索排序 | 真实课程成绩及时间/状态字段；明示计算口径，不能把 0 当缺失数据 |
| 目标测算 | 手动填预计成绩，查看对累计/主修均绩的影响；计算达到目标所需表现 | 选定计分规则、当前已计 GPA 学分、未来课程及学分；模拟值与正式成绩分开保存，目标不可达到时说明 |
| 成绩变动 | 新出分、分数更正、对应均绩变化；可回看上次刷新差异 | 至少两份成绩快照及真实刷新时间，比较稳定课程 ID；失败/空响应不当作成绩删除 |
| 学业负担摘要 | 所选学期单/双周课时、近期考试与待办集中情况，联动日程 | 使用已有课程/考试/作业仓库和同一教学周规则；不重复生成或修改事件 |
| 资料与导出 | 课程备注、成绩导出、公式说明与数据来源 | 用户备注与授权导出的范围；导出格式和隐私偏好后续确认 |

排名、绩点百分位、自动判断毕业或保研资格均需要额外可靠规则/数据，不作为无数据时的估算标签。
