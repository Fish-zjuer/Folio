# AI 控制面（2026-10-22，未发布）

用户更正：当前优先扩展“能控制的值”，不开发新的学习复盘汇总入口，不增加后台模型调用。

原有 `search_records` / `read_record` / `draft_change` 保留。个人任务、课程安排、考试、笔记等修改仍通过可编辑草稿确认后保存，学校原始数据只读。

新增按需工具：

|工具|行为|
|---|---|
|`read_preferences`|读取下表当前设置；不返回API密钥、学校账号、Cookie或成绩|
|`draft_preferences`|每次生成一项可编辑设置草稿，不直接执行|

|设置键|可控值|
|---|---|
|colorMode|system / light / dark|
|horizontalMode|开启/关闭独立横向浏览|
|horizontalPages|自选页面子集，首页保留、至少两页|
|retakeMode|first / highest|
|hideGrades|隐藏/显示成绩与绩点|
|weekendLimit|周末每天手动挂载上限1–12|
|queueWeights|周一至周日7个整数百分比，合计100|

例如：“横向浏览只留首页、工作台、课程、记录”“重修改取首次”“周末手动便签上限改成5”。确认界面可编辑，并检查原设置是否已变更；冲突时不覆盖。它们调用与手动操作相同的主题、导航、学业和队列API。

`agent-core.js` 只在本次请求明确涉及相关设置时附加两项工具。普通对话维持原三项工具；未启用工具的模型伪造调用不会执行。这是避免新增工具开销，不代表模型价格降低。未调用真实付费模型做本轮测试。

学习记录：learning模块支持按需摘要检索、读取单条文字、create/update/delete_learning草稿。创建仅允许日记/笔记，不允许AI伪造录音；音频路径和二进制不进入AI工具结果。课程关联匹配实际课程与学期，不能唯一匹配则拒绝猜测。

下一批控制能力应围绕实际值逐项增加：目标参数、课程本地属性、已有复习/闪卡数据和卡片实例配置。每类都需要独立验证、冲突保护、可编辑确认，不能给模型任意localStorage或原生桥执行权限。
# 2026-10-22 补充：学校同步作业的本地便签动作

学校原始标题、截止日期等保持只读，但本地便签挂载可以修改。AI 在读取目标后，通过 `update_todo` 提交 `pinAction=return_to_inbox` 草稿；用户确认后仅卸下并收回待贴袋，保留同一条学校记录和 queued=true，取消旧挂载日，避免刷新后立即重挂。`hang_now` 为现在挂上；退出队列用 queued=false。不要把 queued=true 解释成“未挂上”，也不要通过复制个人作业绕过此功能。

草稿生成和最终确认均检查学校字段权限；学校作业删除禁止。作业/事项详情另有直接卸下按钮。与左下花朵双击的“仅撤回手动拖出便签”是不同入口，不扩大双击批量撤回范围。
