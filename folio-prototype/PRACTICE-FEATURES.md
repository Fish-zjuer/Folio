# 实践记点：学业内嵌列表与详情

更新：2026-10-16。用户确定放在学业下面，现已制作学业内嵌列表与详情弹层，不增加独立页面或菜单入口。

## 已核对的现有功能

来源为相邻 Celechron-main 的 `lib/page/scholar/practice_score/practice_score_page.dart`、`lib/model/practice_score_item.dart`、`lib/model/scholar.dart`。只读核对，未修改 Flutter。

- 第二、三、四课堂分别显示累计记点和项目明细；美育、劳育为独立的通过状态，未知不当作未通过。
- 项目列表区分已计入与审核中／未计入；按更新时间（缺失时用活动开始时间）倒序。
- 项目详情有项目名称、实际获得记点、课堂类别、审核状态、项目类别、素质类别、参与身份／原因、情况说明、活动起止、最近更新时间。
- 实际记点取学生记录的 jd，不取项目可获分值范围。审核通过、未删除、类别有效且记点非负有限的项目才参与明细合计。
- 平台正式汇总与项目明细是两份来源，可能不同；不能用项目合计静默覆盖正式汇总。仅有旧教务汇总时不能伪造项目。
- 刷新失败保留旧数据；汇总与明细分别记录缓存状态和时间，详情不可用不等于没有项目。

## 已落实的布局

顶部切换第二／三／四课堂，突出选中类的累计记点；下方紧凑白色列表按“已计入”和“审核中／未计入”分组，点击进入完整详情；美育、劳育只呈现通过状态。

用户确认嵌入学业页下方。三类切换为页内操作，选择在本机保存；详情使用共享底部弹层。主页面仍整体滚动，不增加可见滚动条。记点为累计范围，不随上方课程学期切换。用户尚未提出自定义活动、修改官方记点或认定规则等新功能，不自行加入。

## 接入边界

延续本地静态浏览器原型，使用明确标注的虚构样例。后续复用既有卡片独立刷新、成功／失败提醒和缓存保护；不展示内部接口名或工作日志，不引入底部导航、可见滚动条或无依据达标判断。

项目明细默认收起，只保留三类切换、累计记点、美育／劳育状态。原生 details/summary 支持点击或 Enter 展开收起，展开显示原有分组项目；practiceExpanded 在本机保存，切换课堂、刷新卡片和重新加载保持用户选择。收起内容不进入键盘焦点与可访问树。
