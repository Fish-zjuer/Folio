# 便签书桌：参考适配与功能规则

## 视觉来源

用户提供 `sticky-desk.html`，原文件留存在 `assets/sticky-desk-reference.html`。当前工作台沿用浅米色书桌、折角纸、顶部胶带、位移硬阴影，以及咖啡杯、铅笔、盆栽和收纳盒。替代前一版木纹／软板方案，四宫格保留并改为 3px 粗虚线。

没有导入参考中的演示作业，也没有沿用“点击即完成”的脚本。点击便签只打开独立阅读窗，不会自动完成或删除事项。用户已将右下角收纳盒确定为“待贴便签袋”，不收已完成事项；咖啡、铅笔和盆栽仍只是装饰。

四格和书桌共同适配屏幕高度，装饰根据书桌实际高度定位，不拉伸成变形插画。便签仍按事项 ID 保留随机配色、位置、大小和倾角，数量增加后轻微叠压；过多时只滚动便签区，保留无字提示箭头。

## 独立便签阅读

- 表面没有科目、标题、日期、悬停文字或倒计时；点开后仅显示科目、标题、作业链接。
- 不再调用原 `openItem()` 作业管理表单，不显示截止日期、挂载日、队列状态或改期控件。
- 读取已有 `description`，或者个人事项 `body`，作为普通文字展示；没有内容则不放假描述、加载动画或空字段。
- 有 `attachments: [{name,url}]` 时显示附件链接，只接受完整 HTTP(S) URL。所有文本用 textContent，不执行详情里的 HTML／脚本。
- 作业链接依次读取 `url`、`homeworkUrl`、`sourceUrl`；教务作业没有具体链接时回退 `https://courses.zju.edu.cn/`，个人事项没有链接时省略。
- 关闭／遮罩／Esc 返回原便签；焦点限制在阅读窗，返回后恢复原便签焦点。完整作业／待办页仍保留管理功能。

## 待贴便签袋：纯交互提前挂出

- 袋中展示已入队、尚未挂出的未完成事项，按计划日排序；普通待办未明确入队的不混入。袋口显示少量真实待贴纸张，没有数量或日期文案。
- 点袋子展开无字纸张，点一张看科目、标题、链接及已有内容。关闭阅读返回袋子，不丢掉待选事项。
- 可直接把小纸张拖到桌面，也可看完后从阅读纸张上沿拖到桌面；纸张随手移动、落下贴住。没有“立即挂载”等可见文字按钮。
- 这个动作是真实的本地提前挂出：复用 `manualMove()`，保留原截止时间，工作日 1 项、周末默认每天 3 项的手动上限照常生效。已经排在今日稍后才自动挂出的便签也可提前到现在，不重复占名额。
- 无效位置或当日满额时，纸张弹回，不丢弃、不偷偷改日期；可访问状态对读屏说明原因，但不弹可见文字提示。无障碍用户也可在阅读上沿按回车贴出。
- 已贴出的纸张不能拖回袋子；不能通过它延后、藏起冒烟／着火事项。系统原有分批自动挂出逻辑保留，手动选择只是允许提前。
- 前端队列仍以作业页的示例日期作为演示基准；左上时钟独立显示真实时间，本轮未启用真实教务或系统通知。

## 作业描述和附件接入：已核对的边界

本地原项目 `lib/http/zjuServices/courses.dart` 当前通过登录 SESSION 请求 `https://courses.zju.edu.cn/api/todos`，实时失败有缓存回退。`lib/model/todo.dart` 只保留 ID、标题、课程和截止时间，并没有描述／附件抓取逻辑。

因此本轮前端可呈现这些字段，但没有假称自动抓取已经实现，也没有猜作业详情 URL、自动登录或请求私人课程内容。后续真实接入需要：

1. 在已登录的学在浙大环境核实详情及附件接口，保留作业 ID 与 course ID、来源链接。
2. 用户打开便签时按需取该作业详情，避免批量灌入所有描述和文件；成功后本地缓存，失败保留原缓存，仍能打开来源链接。
3. 正文清洗后展示，附件先取文件名／类型／链接，用户点开才下载；过期链接重新鉴权，避免记录 cookie 或将鉴权参数写进日志。
4. 保留本地改期、完成和入队状态，详情刷新不覆盖这些用户选择。

本轮没有修改 Flutter 源码或真实后端。

## 留足完整一天的提醒

剩余天数按日历上的完整可用日计算，不按剩余 24 小时倒数。暂用早上 8:00 为凌晨分界：

- 周三白天交：周日／周一冒烟，周二着火。
- 周三 00:30 交：周二不算完整可用日，周一就着火。
- 周二 23:59 与周三 00:00 视为同一夜的截止，均应留出周一整天。
- 仅有截止日期时不补成零点；视作普通日期，不凭空少给一天。
- 2～3 个可用日为冒烟，≤1 为着火；完成后停止。着火图形已替换为用户 `fire-notes.html` 中的四层火舌、上飘火星和纸张顶部焦边，采用其中等燃烧便签样式，原参考保存在 `assets/fire-notes-reference.html`。不以该文件的演示等级重新定义临期规则，便签仍无文字或日期。

用户尚未定凌晨分界，8:00 是保守试用值，不是教务规则；核心计算参数支持后续调整。这个阶段判定用于便签视觉与改期限制，旧作业页的临期文案逻辑仍独立保留。

## 手动改期限制

- 单项可以提前；推后必须与目标日的一项交换，两项当前都不能冒烟或着火，推后的目标日期也不能已经进入其冒烟／着火阶段。
- 工作日手动最多 1 项；周末暂为每天 3 项，可在作业页“便签分配”调整周末上限。
- 按挂载安排日统计：当天已完成的仍占当天名额，历史积压不在之后每天重复计数。交换双方的接收日期也检查过载。
- 系统自动 `plan()` 不受手动上限限制；不自动取下已挂便签，不改真实截止日期。
- 作业、个人待办中的改期和“现在挂上”都接入相同检查。先校验再同时交换，失败不部分修改。
- 没有可交换项、目标已过载、已冒烟／着火时给出可读提示，不提供强行绕过按钮。

实现：`homework-queue-core.js`、`queue-move-ui.js`；核心新增 8 项测试，配合既有规则测试验收。
