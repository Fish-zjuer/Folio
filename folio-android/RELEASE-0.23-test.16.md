# 0.23-test.16 · 待贴作业便签拖放修复（2026-10-26）

修复 GitHub [#1](https://github.com/Fish-zjuer/Folio/issues/1) 和 [#2](https://github.com/Fish-zjuer/Folio/issues/2)。本版为 Android 修复测试包，versionCode118，沿用原签名，可覆盖 v1.0.1；稳定版 v1.0.1 原附件保留。

## 改动

- 主动从待贴袋拖到书桌的便签不再受当天自动分配配额限制。修改前已复现：当天已有一张作业时，拖放被拒绝，错误仅进入不可见的无障碍状态区；现在按松手位置贴出，保留事项、学校原文和原截止时间。日历手动调期的配额规则保持不变。
- 袋内便签和阅读卡片拖动条使用既有手势锁，触屏、鼠标和笔均不会同时驱动外层横向翻页。修改前斜拖复现普通模式页面偏移12.96px、横向浏览偏移72px；修复后每帧检查偏移为零。
- 拖动中数据刷新保留捕获的便签，松手按ID核对最新记录；已完成、消失或已移出队列的作业不能重新贴上。真实写入失败时保持原记录并显示可见提示。
- 移出板外、系统取消、第二根手指、切页或窗口失焦均取消拖动；正常横向翻页和双击花朵收回功能保留。
