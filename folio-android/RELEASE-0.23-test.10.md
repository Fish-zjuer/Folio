# 0.23-test.10（2026-10-23，本地测试）

设置新增「关系网存储」，初始250个节点位置，每次增加250，最多2000。原有节点、备注和连接不因扩容而改变。

## 数据与 ZIP

- 从单个localStorage全文迁移到分段IndexedDB。每250个节点一段，元信息和所有分段同一事务提交；落盘后才发布状态。localStorage只保留小型定位标记，满额时已提交数据库仍是有效来源。
- 旧数据自动迁移；首次空库恢复先规范化序列化，避免新安装的第一笔保存误报冲突。内部候选test.9因该问题未交付，保留本机诊断；本包已修复。
- 导出标准ZIP，包含节点、备注、父子关系、坐标、折叠状态和容量。导入先检查格式、分段顺序、CRC、容量与关系合法性，预览节点数/容量，用户确认后覆盖。
- 导入事务同时保存原关系网。提供「恢复上次导入前的关系网」，恢复也需确认。预览后本机已变化则拒绝旧确认，不覆盖新编辑。
- ZIP上限32MB，支持Folio未压缩ZIP与标准工具重新压缩的Deflate ZIP；明文独立备份，不要求学校账号。不是任意第三方关系网格式导入器。
- 现有同账号加密离线同步仍包含完整关系网和容量；不会把本机数据库定位标记当作可迁移内容。旧文件缺少关系网字段时仍保留本机数据。
