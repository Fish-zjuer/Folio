# Folio v1.0.1 · 关系网与离线同步

2026-10-23 · Android 9+ · versionCode 111 · 原应用与原签名，可覆盖安装。

本次沿用已经打磨的网页打包界面，保留 v1.0 的工作台、课程、作业、目标和深色模式。实验性 Flutter 工程不属于此次发布。

## 新增与修正

- **关系网**：以自己为中心记录人与事，支持缩放查看、径向展开、折叠、整团脱离与重新连接。暖白外框、浅色圆角地图，跟随深色模式；横向浏览底部留出 52px 加安全区的翻页区域。
- **关系网存储与备份**：初始 250 个节点，设置中每次增加 250，最多 2000；按段写入 IndexedDB，兼容旧数据。支持独立 ZIP 导出、校验预览、确认导入与恢复导入前备份。ZIP 未加密，请自行保管。
- **AI 按需操作**：关系网模糊搜索、分页读取、草稿确认变更；不在初始上下文塞入整个关系网。新增按需读取和修改七类设置，保留冲突检查。学校作业可修改本地便签挂载，学校原始内容仍只读。
- **同账号离线同步**：使用加密 `.folio` 文件在自己的设备之间转移；导入前预览并确认覆盖，保留备份和失败恢复。包括关系网完整内容；这不是自动云同步。
- **Agent 对话**：区分过程说明与工具调用，支持折叠和有限高度滚动；可在设置调整对话上下文与操作轮次。
- **学业与导航**：已出分课程退出待定目标和相关优先安排；横向浏览可以选择页面子集。考试增加完整分页与考场、座位号字段兼容，读取失败保留缓存，实际学校案例仍需复测。
- **交互修正**：便签袋误触挂载可撤回，首页当天栏底边对齐，深色首页摄像头使用橙色。
- 日记、录音代码保留，按用户决定隐藏界面入口；本版不宣传后台录音或自动转写。
