## 本版内容

- 首页对话、今日课程条、右滑周历；工作台 2×2 可替换组件：每日压力、可用空档、专注搭建、专注账本、学习便当等。
- 日程月历/议程、13 节课表、待办与全部个人记录、作业队列与未来两周热力图、课程/考试、学业/成绩、目标测算、设置。
- 深色模式与“跟随系统”切换；工作台压力/专注卡片、作业热力图、目标页底部按钮的暗色细节已补齐。
- 本地系统提醒：默认关闭，开启后按已有提前时间安排，改期/完成取消，点击直达。
- 学校教务连接（直连登录、课表/成绩/考试/作业/实践缓存）、手机使用统计、天气/资讯等原生桥接能力。
- Widget API v1 与卡片包；AI 模型不内置，由用户填写 Base URL、模型和 API Key。
