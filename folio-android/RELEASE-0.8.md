# 0.8-test · 真实公开数据与折纸天气

这版继续使用 Java + 系统 WebView；Flutter 迁移尚未开始。0.6、0.7 发布物保留原件。

## 已接通

- 天气：Open-Meteo 真实城市天气模型数据，默认杭州，可搜索切换城市、手动刷新；15 分钟缓存，失败保留上次真实结果，不再用示例 22°。城市和更新时间可查看。九类图标全部为直边折纸多边形、明暗纸片，无圆弧、描边和柔光。
- 资讯：Hacker News 官方 API 的实时文章，支持原有本地剪报；未接中文新闻源。
- 手机使用：Android 使用情况特殊授权入口、前台活动并集/亮屏/解锁统计、最近七天总时长和每日参考值设置。只取日总量，不向网页返回逐 App 清单。缺数据和未授权不伪装为零；仍需用户真机授权验收。
- 首页右滑：当天课表一列，个人事项为独立无字细条；压缩凌晨/深夜，更多高度给白天时间表。顶栏固定，只有短把手，无长分隔线。

公开接口为固定允许列表，不接收任意 URL。天气及资讯无须输入 Key；AI 仍由用户自己设置 Base URL、模型与 API Key。

## 验证与边界

- 本批功能实现：30 个 Node 测试文件 / 191 项通过；学校离线协议 20 项、使用时长区间计算 9 项通过。
- 浏览器实际天气请求、城市查询、8 篇新闻等 6 项通过。最后的图标美术修改另做语法和浏览器检查：九类共 70 个多边形，0 圆形/曲线路径，工作台实际天气已采用新图标。
- APK 原签名、Manifest 版本与 87 个运行文件的逐字节一致性由 verification-0.8-test.json 记录。无 QA、账号、私钥随 APK 发布。
- 未安装真机，未验证真实 UsageStats 授权、后台可靠性、摄像头或物理手势。
- 学在浙大作业/实践及免官方网页登录的 SSO 仍未真实账号验收。AI 记忆问答更新、完整后台同步与通知闭环仍未完成。不能称所有功能已真实可用。
