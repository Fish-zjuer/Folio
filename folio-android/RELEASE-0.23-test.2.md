# 0.23-test 修订 2

2026-10-22。仍属于 0.23 测试序列，不更新正式 V1.0，不发布 GitHub。

- 修复 AI 拒绝卸下学校同步作业便签的问题。`update_todo` 新增本地 `pinAction=return_to_inbox|hang_now`，不开放学校标题、截止日期等原始字段。
- `queued` 只表示是否属于队列；卸下后保留 queued=true，清除本地挂载及自动挂载日期，等待再次手动挂上。退出队列仍用 queued=false。
- 草稿编辑器保留学校原始字段只读；确认保存时再次检查权限，不能借编辑草稿绕过限制。学校作业删除同样禁止。
- 学校作业和个人事项详情增加“卸下并收回待贴袋”，无需调用模型。
- 不复制同名作业，不修改学校服务器，不读取聊天中提供的真实个人作业缓存。

验证：46 个 Node 测试文件全部通过，包含 5 个新增权限/持久化/重试检查；隔离浏览器 8 项检查通过，覆盖实际确认表单、重载、重新规划及直接卸下。均为虚构数据，不等同于真机或真实模型验证。

原 0.23-test APK 和对应源码包保持不变。本修订 Android 内部版本号 102，可覆盖 0.23-test / V1.0；Flutter 独立工程不混入该安装包。
