## 变化

1. 26枚学习卡按实际点中的图形、色块、日期和记录打开上下文菜单。重点区与主要操作先显示，相关内容分组，长组可搜索/折叠；说明在底部折叠。压力及专注/任务/课程数字卡详情也分层。
2. 课程关联后续排课和对应复习，月相按夜编辑，考试区分待考/已结束，学校已交与本地完成分开；成绩沿用全局隐私设置。闪卡扇打开当前前排卡，作业步骤突出下一步。
3. 增加课程安排（上课/实验）类型；显示为课程卡和课程时段，可独立入队，不挤占普通作业/待办名额。
4. 手动与AI草稿确认时可多选显示位置，入队独立；支持多个提前提醒分钟数，逗号分隔。
5. AI的 `--:--` 时间改为时间待定，可保留已知日期直接确认，之后补时间。学校刷新保留本地展示设置。
6. Widget API v1继续兼容与可扩展，补充可选source、personal/itemId元数据。
