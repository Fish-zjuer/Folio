## 通知

设置 → **成绩更新通知设置** 可开关，并申请系统通知权限。后续主动同步发现新成绩时，App 在后台才发系统通知，正文不含分数；点通知进入对应成绩。前台仅提示有更新，不强制揭晓。

**尚无后台定时查分**：只有已发起的同步在后台完成时会通知。App 被结束后不会继续抓取。待办提醒仍以 App 内机制为主，不能把本包当作完整的后台提醒服务。

## AI 范围

使用 OpenAI 兼容 Chat Completions 协议，模型需支持工具调用；图片／PDF还需厂商与模型兼容。思考强度“自动”不发送 `reasoning_effort`。首轮仅提供规则、工具与用户消息，再按需检索本机课程、日程、作业、待办、考试、成绩、目标；成绩读取限制在相关明确请求。每轮最多 8 次模型往返，支持停止，累计实际返回的命中／未命中输入和输出 token；未返回的项目显示 `—`。

AI 对个人待办／考试的新增、更新、删除生成可编辑草稿，确认才写入；收起、外部点击、离页或重开保留，确认／取消后结束。修改前必须读取，确认时检查并发变化。学校考试、原始成绩只读；没有任意 URL、代码执行或自动提交学校作业工具。消息、附件与按指令读取的资料发送给用户配置的模型地址。
